📊 Sales Analysis Dashboard — Power BI + Excel
This project analyzes sales performance across channels, products, regions, and customer demographics.
Data cleaning and transformation were done in Excel, and visualization was built in Power BI.

🔧 Tools Used
Microsoft Excel (Cleaning & Transformation)

Power BI (Dashboard & Visualization)

📌 Key KPIs
Total Sales

Online vs In‑Store Sales

Regional Max Sales

Average Sales by Age Group

Product‑wise Sales Count

📈 Dashboard Insights
Online channel contributes the highest share of sales

Binder and Pen Set are top‑selling products

Middle‑aged customers generate strong average sales

Sales trend shows consistent activity across the month

Sales representatives show varied performance across product categories
